## ✨ Features
 
- ⏳ Startup screen with a loading progress bar
- 💹 Live quotes loading with an animated spinner
- 🎨 Colorful terminal UI powered by Rich
- ⌨️ Command system with an options menu

## 🚀 Getting started
 
Requires **Python 3.10+**.
 
```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/Terminal_Bloomberg.git
cd Terminal_Bloomberg
 
# Create and activate a virtual environment
python3 -m venv .venv
source .venv/bin/activate
 
# Install dependencies
pip install rich
 
# Run
python3 -u Terminal_BloombergOpenSource.py
```
